Build Log

A data-quality auditor for computer vision datasets. Points it at a folder of training images and it finds the files quietly wrecking a model: duplicates, photos leaked between the training and test split, blurry shots, and rotation-tag bugs that silently invalidate bounding boxes.

What's built and validated

Duplicate detector

Validated ✓

Flags near-identical photos so the same shot doesn't get counted twice in a training set.

256-bit perceptual hash (OpenCV BlockMeanHash) → Hamming distance between two images
Same image, tiny noise0.0
Two different images17.0
Threshold set
≤ 5 → duplicate. Picked under time pressure once real numbers were in hand — biased low on purpose, since missing a real duplicate costs more than an occasional false flag. Provisional: recalibrate against real photos before final submission.

Leakage detector

Validated ✓

Same check as duplicates, run between the training pile and the test pile — catches the same photo appearing in both, which fakes a model's accuracy score.

Reuses the duplicate hash + threshold, applied across two groups instead of within one
Train image vs. its test-side twin0.0
Train image vs. unrelated test image17.0
No new decision
Inherits the duplicate threshold above — this is the highest-consequence defect in the whole project, since a leaked test image makes a bad model look accurate.

Blur detector

Validated ✓

Flags photos too out-of-focus for a human, or a model, to learn anything real from.

Laplacian variance — sharp edges score high, smooth blur scores low

EXIF orientation

Validated ✓

Catches photos whose hidden "rotate me" tag doesn't match the raw pixels — the exact bug that silently misplaces every bounding box on a sideways phone photo.

Reads the raw EXIF Orientation tag (Pillow), flags anything but the identity value
