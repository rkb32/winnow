# Code of conduct

Winnow is a small open-source project. Be respectful, assume good faith, and keep discussion about the work.

Not acceptable: harassment, personal attacks, discriminatory language, or publishing someone's private information.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat offenders. To report a problem, contact the maintainer, Ranjeeth Burujula, through [github.com/rkb32](https://github.com/rkb32).
